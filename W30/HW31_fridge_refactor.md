# Домашнее задание — завершаем рефакторинг холодильника

**Исходный код:** [GitHub — webinar30](https://github.com/FullStack66-webinars/w26/tree/HW_add_2/webinar30)

Продолжаем работу с приложением, которое начали рефакторить на вебинаре.

## 1. Доработать DOM (`ui.js`)

- Добавить информационную панель над списком продуктов.
- В обычном режиме отображать **«Основной список»** (зелёная панель).
- При работе с черновиком — **«Черновик»** (жёлтая панель).
- Создать функцию `updateMode()` для обновления панели и состояния кнопок.
- Использовать уже подготовленные CSS-классы `.mode-panel` и `.draft-mode`.

## 2. Управление кнопками

- Без черновика доступна только кнопка «Создать черновик».
- При активном черновике доступны только «Сохранить изменения» и «Отменить изменения».
- Управлять доступностью через свойство `disabled`.

## 3. Обновить `main.js`

- Вызывать `updateMode()` из общей функции `render()`.
- После добавления продукта очищать оба поля.
- При ошибке добавления выводить сообщение на странице.
- При пустом результате фильтрации показывать «Продукты не найдены».

## Проверка результата

Создать черновик → добавить продукт → переключить фильтры → отменить изменения. Основной список должен остаться прежним.

Повторить с сохранением. Изменения должны перейти в основной список.

### ⭐ Дополнительное задание

Доработать кнопку `Show information`: при нажатии показывать название, категорию и статус продукта, не изменяя `bought`.

Попробовать реализовать через делегирование событий.

**Результат:** приложение с понятным отображением текущего режима и корректной работой черновика.
