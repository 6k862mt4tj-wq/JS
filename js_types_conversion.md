В JavaScript приведение типов делится на два вида: **явное** (когда ты сам используешь функции `String()`, `Number()`, `Boolean()`) и **неявное** (когда движок JS делает это сам при математических операциях или сравнении `==`).

Здесь собрана полная шпаргалка, как разные типы данных ведут себя при трансформации.

## 1. Сводная таблица (Шпаргалка)

Главная таблица, которую нужно держать в голове. Как базовые значения приводятся к трем основным типам:

| Значение `val`           | `String(val)`       | `Number(val)` | `Boolean(val)` |
| ------------------------ | ------------------- | ------------- | -------------- |
| `undefined`              | `"undefined"`       | `NaN`         | **`false`**    |
| `null`                   | `"null"`            | **`0`**       | **`false`**    |
| `true`                   | `"true"`            | `1`           | `true`         |
| `false`                  | `"false"`           | `0`           | **`false`**    |
| `""` (пустая строка)     | `""`                | **`0`**       | **`false`**    |
| `"   "` (только пробелы) | `"   "`             | **`0`**       | `true`         |
| `"123"`                  | `"123"`             | `123`         | `true`         |
| `"0"`                    | `"0"`               | `0`           | **`true`**     |
| `"abc"`                  | `"abc"`             | **`NaN`**     | `true`         |
| `0`, `-0`, `0n`          | `"0"`               | `0`           | **`false`**    |
| `NaN`                    | `"NaN"`             | `NaN`         | **`false`**    |
| `[]` (пустой массив)     | `""`                | **`0`**       | **`true`**     |
| `[1]`                    | `"1"`               | `1`           | `true`         |
| `[1, 2]`                 | `"1,2"`             | `NaN`         | `true`         |
| `{}` (пустой объект)     | `"[object Object]"` | `NaN`         | **`true`**     |

---

## 2. Логическое приведение (Boolean)

Самое простое правило в JS. Существует всего **7 ложных (falsy)** значений:

1. `false`
2. `0`
3. `-0`
4. `0n` (BigInt ноль)
5. `""` (пустая строка)
6. `null`
7. `undefined`
8. `NaN`

> **Важно:** Абсолютно всё остальное приводится к `true` (truthy). Включая пустые массивы `[]`, пустые объекты `{}`, строку `"0"` и строку `"false"`.

---

## 3. Численное приведение (Number)

Происходит неявно при математических операциях (кроме сложения со строкой) и строгом сравнении: `-`, `*`, `/`, `%`, `>`.
Также можно вызвать с помощью унарного плюса: `+"123"`.

**Специфичные правила:**

- Строки обрезаются от пробелов по краям. Если после обрезки строка пустая — это `0`. Если внутри не только цифры — `NaN`.
- `null` превращается в `0`.
- `undefined` превращается в `NaN`.
- `Symbol` вызывает ошибку `TypeError` при попытке привести его к числу.

---

## 4. Строковое приведение (String)

Происходит неявно при сложении `+`, если хотя бы один из операндов является строкой.

- Массивы преобразуются в строку путем объединения элементов через запятую: `[1, 2, 3]` → `"1,2,3"`.
- Обычные объекты преобразуются в классическое `"[object Object]"`.

---

## 5. Неявное приведение: Главные «ловушки»

### Математика: Плюс (+) против остальных

Оператор `+` работает и для сложения чисел, и для склеивания строк (конкатенации). Если хотя бы с одной стороны строка, JS приведет вторую сторону тоже к строке.
Все остальные операторы (`-`, `*`, `/`) всегда приводят операнды к **числу**.

```javascript
"2" + 2; // "22" (строка, так как есть +)
"2" + "2"; // "22"
2 + 2 + "2"; // "42" (сначала 2+2=4, затем 4+"2")
"2" + 2 + 2; // "222" (строка с самого начала)

"6" - 2; // 4 (число, минус работает только с числами)
"6" * "2"; // 12 (число)
"foo" - 2; // NaN (строка "foo" стала NaN)
```

### Нестрогое равенство (==)

При использовании `==` JS пытается привести типы к одному (обычно к числу). **Всегда используй `===**`, чтобы избежать этого, но если нужно прочитать чужой код, помни эти правила:

1. `null == undefined` (это `true`, но они не равны ничему другому в языке).
2. При сравнении строки и числа, **строка становится числом**.
3. При сравнении с `boolean`, **boolean становится числом** (`true` -> 1, `false` -> 0).
4. При сравнении объекта с примитивом, объект приводится к примитиву.

**Классические примеры безумия JS:**

```javascript
"0" == 0; // true  ("0" становится 0)
0 == []; // true  ([] становится "", а "" становится 0)
"0" == []; // false (строка и объект - объект [] становится "", "0" == "" -> false)
false == "0"; // true  (false -> 0, "0" -> 0)
false == []; // true  (false -> 0, [] -> 0)
"" == false; // true  ("" -> 0, false -> 0)
```

## 6. Как объекты приводятся к примитивам

Когда JS нужно превратить объект или массив в примитив (например, при `obj + 1` или `String(obj)`), он использует внутренний алгоритм `ToPrimitive`. Он ищет методы в объекте в таком порядке:

1. `obj[Symbol.toPrimitive](hint)` — если метод задан разработчиком, вызывается он.
2. Если нужна строка (hint: "string"): пытается вызвать `obj.toString()`, если возвращает не примитив — вызывает `obj.valueOf()`.
3. Если нужно число (hint: "number" или "default"): пытается вызвать `obj.valueOf()`, затем `obj.toString()`.

По умолчанию у объектов метод `valueOf()` возвращает сам объект, поэтому при приведении к строке или числу в итоге почти всегда срабатывает `toString()`, который возвращает `"[object Object]"`. У массивов `toString()` возвращает элементы через запятую.
