# Домашнее задание: список продуктов и состояние приложения

## Короткое задание (подсказки см. ниже)

Есть массив объектов:

```js
const products = [
    {
        id: 1,
        name: "Молоко",
        category: "Молочные продукты",
        bought: false
    },
    {
        id: 2,
        name: "Хлеб",
        category: "Выпечка",
        bought: true
    },
    {
        id: 3,
        name: "Сыр",
        category: "Молочные продукты",
        bought: false
    },
    {
        id: 4,
        name: "Яблоки",
        category: "Фрукты",
        bought: false
    }
];
```

Нужно сделать приложение для работы со списком продуктов.

### 1. Вывести список

Выведите все продукты из массива в DOM.

Купленные продукты должны визуально отличаться от некупленных.

---

### 2. Добавить продукт

Добавьте форму:

```text
Название:   [                ]
Категория:  [                ]

[ Добавить ]
```

После добавления должен создаваться новый объект:

```js
{
    id: ...,
    name: "...",
    category: "...",
    bought: false
}
```

Новый продукт сначала добавляется в массив, после этого обновляется DOM.

Не допускайте дублей продуктов.

---

### ⭐ 3. Куплено / не куплено

При клике на продукт меняйте его состояние:

```js
bought: false
```

на:

```js
bought: true
```

и обратно.

Изменение должно происходить в массиве данных, а не только в DOM.

---

### ⭐ 4. Фильтрация

Добавьте кнопки:

```text
[ Все ]
[ Нужно купить ]
[ Куплено ]
```

Используйте `filter()`.

Фильтрация не должна изменять основной массив.

---

### ⭐⭐ 5. Черновик списка

Добавьте кнопку:

```text
[ Создать черновик ]
```

Сначала попробуйте создать копию:

```js
const draftProducts = [...products];
```

Измените один из объектов в `draftProducts` и проверьте, изменился ли исходный массив.

После этого создайте черновик через:

```js
structuredClone(products)
```

Добавьте:

```text
[ Сохранить изменения ]
[ Отменить изменения ]
```

При сохранении черновик становится текущим состоянием списка.

При отмене основной массив не должен изменяться.

---

# Описание и подсказки

Главная идея:

```text
данные
↓
изменение массива
↓
рендер
↓
DOM
```

DOM не должен быть основным хранилищем данных.

Для отображения списка имеет смысл использовать отдельную функцию, например:

```js
function renderProducts(productsToRender) {
    // ...
}
```

После изменения данных список можно отрисовать заново.

Для поиска нужного продукта используйте его `id`.

Подумайте, как связать `id` объекта с DOM-элементом.

При фильтрации основной массив должен оставаться неизменным:

```text
products
↓
filter()
↓
новый массив
↓
renderProducts()
```

Обратите внимание на разницу:

```js
const copy = products;
```

```js
const copy = [...products];
```

```js
const copy = structuredClone(products);
```

Проверьте:

```js
products === copy
```

и:

```js
products[0] === copy[0]
```

Попробуйте объяснить результат самостоятельно.

## Вспомните прошлое ДЗ

Некоторые идеи и функции из предыдущей работы могут пригодиться и здесь.

Но структура данных изменилась:

```js
"Молоко"
```

теперь стало:

```js
{
    id: 1,
    name: "Молоко",
    category: "Молочные продукты",
    bought: false
}
```

Подумайте, что можно переиспользовать, а что придётся изменить.
